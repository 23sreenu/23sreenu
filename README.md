## 🔬 Research Focus

I'm a graduate researcher at **Texas A&M University** working on **computer vision for precision livestock management**. My current research combines state-of-the-art object detection and instance segmentation models to enable automated, AI-driven monitoring of cattle in farm environments.

**Current Projects:**
- 🐄 Real-time cattle detection & segmentation using **YOLO + SAM (Segment Anything Model)**
- 🏷️ Individual cattle re-identification across multiple camera viewpoints
- 🩺 Health anomaly detection via pose estimation and behavioral analysis
- 📍 Integration of vision models with edge computing for on-farm deployment
